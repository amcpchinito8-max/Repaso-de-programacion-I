Informe de Repaso: Programación II (Trayecto 2 - Fase 1)

Este documento presenta el informe de repaso individual correspondiente a la unidad curricular Programación II de la Universidad Politécnica Territorial José Antonio Anzoátegui, extensión Guanta. El objetivo de este material es revisar y afianzar los conceptos fundamentales del paradigma orientado a objetos y la arquitectura web desarrollados durante la primera fase del trayecto.

A lo largo de este trabajo abordo los pilares de la programación orientada a objetos, comenzando por la definición de clases y la creación de objetos o instancias. Explico cómo estructurar estos elementos gráficamente mediante diagramas de clases UML y cómo proteger la información del código utilizando especificadores de acceso como público, protegido y privado. También repaso la función de los métodos constructores para inicializar variables y el uso de la herencia para reutilizar código de forma eficiente entre clases hijas.

De igual manera, profundizo en conceptos más avanzados como las clases abstractas para crear plantillas base, el polimorfismo para ejecutar diferentes comportamientos bajo un mismo método y el uso de interfaces como contratos obligatorios en el software. Finalmente, conecto toda esta base teórica con el desarrollo web actual, analizando el patrón de diseño Modelo-Vista-Controlador tanto en frameworks de PHP como Laravel, como en el patrón equivalente de Django en Python.

El contenido se presenta como un resumen técnico y teórico estructurado para consolidar los conocimientos requeridos en la evaluación de la materia y servir como guía de consulta en el repositorio.
